# CodeFlux

CodeFlux is an AI & Digital Marketing agency website — showcasing our services, portfolio, and helping businesses grow through smart digital solutions and AI-powered marketing strategies.

## About

CodeFlux helps businesses leverage AI and digital marketing to reach their audience, grow their brand, and drive results. This website serves as our online presence — highlighting our services, past work, and how to get in touch with us.

## Services

- AI-Powered Marketing Solutions
- Social Media Marketing
- SEO & Content Strategy
- Web Design & Development
- Brand Strategy & Consulting

## Tech Stack

- Next.js
- Tailwind CSS
- TypeScript

## Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
